# 소재 레이더 (news_radar)

연예·스포츠 분야에서 지금 뜨는 소재를 자동으로 모으고, 카드뉴스로 만들 가치가 있는지 점수와 근거를 보여주는 웹 도구입니다.

- 하루 3~4개 카드뉴스 소재를 더 빨리, 더 근거 있게 고르기 위해 만듭니다.
- 구글 트렌드와 뉴스 RSS에서 후보를 모으고 → 규칙으로 거르고 → 화제성 점수와 국면(상승 중/정점/하락)을 매겨 → 3칸 보드로 보여줍니다.
- 발행한 게시물의 플랫폼별 성과를 기록해, 어떤 소재가 어느 플랫폼에서 잘 되는지 쌓아갑니다.

전체 기획은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 폴더 구조

```text
news_radar/
├─ config/              설정 파일 (코드를 고치지 않고 동작을 바꾸는 값)
│  ├─ categories.yaml   카테고리와 카테고리별 RSS 목록
│  ├─ sources.yaml      수집 소스 목록과 켜짐 여부
│  ├─ scoring.yaml      점수 가중치, 최소 보도량, 국면 판단 기준
│  └─ exclude.yaml      제외 키워드
├─ collector/           수집 파이프라인 (Python)
│  ├─ sources/          소스별 수집 모듈
│  ├─ filter.py         규칙 필터 · 사건 묶기
│  └─ score.py          점수 · 국면 계산
├─ web/                 웹 보드 (React + TypeScript)
├─ db/                  데이터베이스 생성 스크립트
├─ tests/               테스트와 샘플 응답
├─ docs/                PLAN.md(기획서), DATA.md(데이터 형식)
└─ .github/             자동 실행 설정, 이슈·PR 템플릿
```

## 실행 방법

지금은 기본 틀만 있는 단계라 실행할 프로그램이 아직 없습니다. 이슈가 하나씩 끝날 때마다 여기에 실행 방법을 추가합니다.

| 무엇 | 언제 생기나 |
| --- | --- |
| 데이터베이스 만들기 | #2 데이터 구조 확정 |
| 수집 파이프라인 실행 (`python -m collector ...`) | #3 ~ #6 |
| 웹 보드 실행 (`cd web && npm run dev`) | #7 |
| 자동 수집 (3~4시간마다) | #11 |
| 웹 배포 주소 | #12 |

## 설정 바꾸기

카테고리, 소스, 점수 가중치, 제외어는 모두 `config/` 폴더의 파일에서 바꿉니다. 코드를 고칠 필요가 없습니다.
변경 이력이 남도록 설정 파일 수정도 PR로 올립니다.

## 작업 방식

이슈 하나 = 브랜치 하나 = PR 하나로 작업하고, 머지는 담당자가 직접 합니다.
에이전트 작업 규칙은 [CLAUDE.md](CLAUDE.md)를 봅니다.

API 키와 비밀번호는 절대 코드에 넣지 않고 GitHub Secrets에만 보관합니다.
